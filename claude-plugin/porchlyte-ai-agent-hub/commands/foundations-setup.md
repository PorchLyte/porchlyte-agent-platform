# Foundations setup

Before you say a word, call `get_setup_status` and `get_foundations` on the PorchLyte connector.

Three situations:

1. **All complete** — tell them Foundations are already saved to their PorchLyte account. Offer to review or update one.
2. **Some complete / some empty or partial** — resume only what's missing. Prefer https://aiagents.porchlyte.com for the wizard; offer chat interview if they want.
3. **All empty** — walk Voice → Brand → Local. One question at a time. After each foundation, show the prose, get confirmation, then `save_foundation`.

Never invent answers. Never skip confirmation before save.
