# PorchLyte Platform — What We're Building

**For:** Tracy · PorchLyte
**Date:** July 15, 2026

Right now the users are in a black box. They don't know if their Foundation actually saved, hard to track which agents they've set up and how much, whether they're using their AI team the way they should be, or what to do next to get more out of it. You can't see any of that either, so when someone says "this isn't working," you're guessing along with them.

This build fixes that on both sides. Members get a real home with a clear picture of their own setup. You get a dashboard that shows you exactly where every member stands, usage analytics, everything in one place.

---

## 1. The memory system

The engine behind everything else. This is what lets a member's AI team remember them on any device, forever, instead of just on one laptop. 

## 2. The PorchLyte hub

Your members' home base: one login at porchlyte.com for everything. Here's what lives inside it.

**Foundations area** — where members set up and manage their Voice, Brand, and Local. A clean onboarding experience to get set up the first time, and a simple way to come back and read or edit any of it whenever something changes.

**A dedicated space for each AI team member** — Darla, Chloe, Ella, and the rest each get their own home inside the hub. Learn what they do, see the prompts and tools built for them, and check their actual status: hired or not, set up or not, and how they're being used in the member's workflow. This is the piece that kills the "wait, do I even have Rhonda set up?" confusion for good.

For team members who run on a schedule, like Darla's morning brief, members get a simple panel showing whether it's active, what time it's set for, and when it last ran, with an easy way to pause it or turn it back on. The schedule itself still gets set up through Claude, but once it exists, members can see and manage it right from the hub instead of losing track of it.

**Course area** — built to be genuinely next-level, not just lessons dumped into a template. Room to make this feel like a real learning experience, not an afterthought.

**Community area** — same idea. A space that can be shaped and styled to feel like it's genuinely yours, not a generic 3rd party.

**Account area** — membership status, connected Claude, billing info, the basics every member expects to find in one place.

**Admin area (for you)** — member profiles, setup status across your whole membership, usage analytics, and stats on how the AI team is actually being used. This is where "who's stuck, who's thriving, what's working" becomes something you can see at a glance instead of guess at.

## 3. Setup, made easy

A simple guided setup on the website where members build their Voice, Brand, Local, and hire their team, no Claude chat required but can also be done inside claude since it all syncs both ways. They can come back and edit anything anytime, and they can always see exactly what's set up, what's missing, and what to do next. No more wondering if it worked. You get a dashboard showing exactly who's finished setup and who's stuck, so you can reach out before they get frustrated instead of after.

## 4. One simple connection to Claude

Today members install two separate things and it's been a headache. This becomes one single install: everything Claude needs to run the team properly, plus the connection back to their PorchLyte account, bundled into one clean step. Install once, and their Claude is fully wired up to everything they just set up on the hub.

## 5. Courses

Your course content, moved out of GoHighLevel and into the hub. Same lessons, same structure, now living under one login with everything else with ability to customize and tweak lessons and interface to be relevant to what needs to be done.

## 6. Community

A simple, clean community space inside the hub: posts, replies, a few topic areas, pinned announcements. Built to feel like "your place," and relevant to the course and platform discussions and usage.

## 7. Getting listed with Anthropic *(optional, later)*

Anthropic keeps a public directory of tools like yours. Getting listed is a nice trust badge, but members never need it to use their AI team; it's a bonus you can pursue once everything else is running, not something we build first.

## Some benefits of this upgraded setup

- **Solid, scalable infrastructure.** This isn't a patchwork of workarounds, it's built the right way from the ground up. Whether you have 50 members or 5,000, it holds up the same.
- **A genuinely smooth, high-quality experience.** From the first login to daily use, members get something that feels premium, not something they have to fight with.
- **No more black box.** Members always know where they stand and where their AI team is, how it's being used, how to use it better. You always know where they stand. That alone turns a lot of support headaches into non-issues.
- **You can drive it yourself.** You already like using Claude and know your way around Claude Code. Once this is built, you can make updates, tweak content, adjust design, and add things yourself whenever you want, without waiting on anyone.
- **Low maintenance once it's live.** Built to run quietly in the background. Real infrastructure, not something that needs constant babysitting.
